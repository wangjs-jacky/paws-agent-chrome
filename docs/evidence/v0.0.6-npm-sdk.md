The production build was served by the isolated local protocol fixture. Only
Ego browser automation was used; `chrome.runtime` and `chrome.storage` were
shimmed in the same-origin test iframe. This is not a real installed MV3 or
full-browser-restart test, and does not connect to a production account.

Verified QR binding, initial machines/recent-directory snapshot, directory
creation approval retry, encrypted prompt with page context, remote reply,
new-conversation reset, and page-refresh reconnect without another QR link.
The fixture recorded two spawn requests, one approved creation, one decrypted
prompt, and zero privileged approval RPCs. Each verified browser state was
reported to Happy; the isolated browser task and fixture server were closed.
