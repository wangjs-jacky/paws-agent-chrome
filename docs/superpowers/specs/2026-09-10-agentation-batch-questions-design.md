# Agentation 页面批注与 Paws 批量提问：第一版设计

日期：2026-09-10

状态：聊天中的第一版范围已获用户确认；本文待用户审阅。尚未实施、安装依赖或获得第三方发布授权。

## 1. 目标与边界

用户在阅读普通网页或 Paws 会话时，选中文字或点击元素，连续记录问题，检查上下文后一次性发送给 Paws Agent，并在现有插件会话内查看回复。

第一版包含：Agentation 文字/元素批注、增改删、扩展本地草稿、单页面批次预览与发送、配置折叠、原有会话与跳转功能。

第一版不包含：Web/PC 配置同步与导入协议、模型能力扩展、本地文件桥梁、公开网站评论、多人协作、跨页面合并批次、截图/区域圈选、自动修改文件、独立逐条回答卡片。回答以现有聊天消息展示，提示 Agent 按批注编号作答，不依赖模型严格输出结构化数据。

支持范围为 Chrome 可注入扩展内容脚本的 HTTP(S) 顶层页面。不承诺浏览器内部页、内置 PDF 阅读器、跨域 iframe、所有 Shadow DOM 或虚拟列表的定位能力。

## 2. 已核实的现状

- 当前扩展是 TypeScript + esbuild，没有 React 依赖。
- `src/content.ts` 向原网页加入扩展来源的 `panel.html` iframe；账号和 SDK 连接在 `src/panel.ts` 中。
- `src/pageContext.ts` 只组合标题、URL 和至多 6,000 字符的选择文本，没有正文提取或批注模型。
- `src/chromeStorage.ts` 已使用 `chrome.storage.local`；配置、凭据仍沿用现有机制。
- 原工作树 `feat/session-link` 中存在尚未提交的会话跳转功能，必须完整保留，不能混入本设计提交。
- 上游 Agentation 仓库的 `package/package.json` 当前为 3.0.2；React / React DOM peer 版本要求为 >=18。仓库版本不等于已经验证的 npm 发布版本。
- 上游公开了 Agentation 组件、Annotation 类型和部分工具；Annotation 包含 comment、selectedText、nearbyText、elementPath 等字段。尚未验证其组件受控状态、默认存储和扩展隔离兼容性。

## 3. 接入选择

采用“页面批注层 + 扩展会话面板”的分层接入，不把 Agentation 放入无法直接访问原页面 DOM 的聊天 iframe，也不将整个现有面板重写成 React。

Agentation 的组件/依赖随扩展本地打包，不使用 CDN、远程脚本或网页自身的 React。优先使用公开 API，通过适配层接入；不默认开启 Agentation 自带的远端同步、MCP 或服务器连接。

实现计划的第一个检查点必须确认：注册表可用版本及完整许可、批注增改删与恢复接口、关闭网站 localStorage 的方法、样式/事件隔离和 MV3 构建兼容性。存在不满足设计的硬限制时，先报告具体差异；不得默默启用网站存储、重写第三方核心或扩大依赖服务。

## 4. 用户体验

### 主面板与设置

- 主面板显示当前执行目标摘要、连接状态、输入框、批注数量、发送按钮及当前会话入口。
- 齿轮展开现有服务器、账号、设备与工作目录设置。首次未配置时提供明确入口，不显示虚假的就绪状态。
- 第一版的“项目”只是现有设备 + 工作目录的可读摘要，不新增跨端工作空间实体。
- 设备离线、连接失败和权限确认保持显式可见，不隐藏在齿轮内。

### 批注与草稿

- 用户主动开启批注模式；未开启时不拦截原页面正常选择和点击。
- 选中文字或点击元素后填写问题，保存成带稳定 ID 的批注，支持编辑和删除。
- 批注模式与聊天入口协调，避免两套浮层重叠；退出模式恢复页面交互。
- 问题列表展示编号、引用摘要和问题。点击列表项尝试滚动/高亮对应原文。
- 页面刷新后恢复草稿；不同标签页的草稿独立，避免互相覆盖。同一标签页导航到其他页面时切换草稿，不混入新页面批次。
- 本地草稿按标签页生命周期和页面身份隔离；关闭标签页后不保证恢复，浏览器重启恢复不属于第一版。提供明确的清空当前页面草稿入口。

### 预览与发送

- 有批注时，即使总输入框为空也可发送；没有批注时保留原有普通提问。
- 发送前展示本次问题、引用、必要上下文与来源，以及真实的目标设备、目录和会话。用户可取消并继续编辑。
- 确认后冻结该批次内容和目标，创建本地 batchId，沿用现有会话；尚无会话时沿用原创建流程。
- 发送中禁止重复提交同一批次；目标切换或新建会话使旧操作失效，不能把旧结果写入新会话状态。
- 确认成功后只移除该批次中版本未变化的草稿；发送期间新建或编辑的草稿不得被清空。
- 失败保留草稿和错误原因。超时/断线且不能确认服务端是否接收时标记“发送结果待确认”，不自动重发；提示先查看会话，再由用户决定是否重试。
- batchId 是本地关联标识，不宣称 SDK/后端提供 exactly-once 或幂等保证。

## 5. 模块职责与安全边界

| 模块 | 职责 | 禁止承担 |
|---|---|---|
| 页面 Agentation 适配层 | 页面选择、批注 UI、引用采集、最佳努力定位 | 账号凭据、SDK 调用、自动发问 |
| 扩展消息与草稿协调层 | 校验来源/结构，按标签页和页面串行处理草稿操作，持久化 | 执行页面传来的 shell、HTML 或任意命令 |
| 扩展面板 | 设置、草稿预览、用户发送确认、SDK 会话和回复 | 将凭据传回原网页 |
| 纯数据模块 | 批注规范化、长度限制、批次快照、提示词组合 | DOM 副作用、网络请求 |

需要标签页身份和跨上下文消息时使用扩展 runtime 与轻量 service worker 协调，不请求浏览历史等不必要权限。runtime sender 的扩展身份、标签页与 frame 信息必须校验，不能信任 payload 自报身份。

原网页和所采集文本始终视为不可信数据。页面发来的内容只能形成待审阅草稿，不能触发发送、切换配置或读取凭据。若保留 window 消息，只用于非特权通知；source/origin 检查不能替代真实的扩展 UI 发送确认。所有引用按纯文本渲染。

批注 UI 所在 DOM 并非对宿主网站保密的安全容器；扩展存储隔离不代表网站无法观察页面上的可见文字或交互。产品不作此承诺。

## 6. 数据、上下文与定位

扩展自己的草稿结构保存 schemaVersion、id、revision、pageKey、来源标题/URL、quote、prefix/suffix、elementPath、comment 和时间戳。只保留本功能需要的字段，不整包保存上游事件或 DOM。

页面身份包含实际路由变化（包括 query 和 hash），使用摘要形成存储键；原 URL 只留在扩展存储。发送预览默认去掉 URL query/hash，用户可明确选择包含完整链接，避免隐式携带令牌，同时允许有需要的会话路由。

默认只采集用户选中的文字和局部邻近文本，不抓整页、完整聊天历史、隐藏内容、密码框或表单输入值。元素批注只采集必要的可见标签/文本及定位信息。

初始上限：每页 20 条批注、每条问题 2,000 字符、引用 6,000 字符、相邻文本总计 2,000 字符、整批提示词 40,000 字符。上下文截断必须在预览中标明；问题过长或整批超限时阻止发送并让用户缩减，不静默丢弃问题。

提示词按页面公共背景和逐条编号组织，清楚分隔“用户问题”和“不可信页面引用”，请求逐项回答。文字引用不是可执行指令，批注也不新增任何文件或命令权限。

定位先验证仍匹配原引用的元素/文字，再使用引用与前后文尝试恢复。选择器或坐标不能单独证明命中；多处歧义、原文未渲染或内容已修改时展示保存的引用并提示“原文位置已变化”，不跳到猜测位置。不要求读取 Paws 私有页面状态或预设消息 ID 一定存在。

草稿写入扩展 `chrome.storage.local`，不得回退到宿主 localStorage。写入失败时明确显示未保存并保留内存内容；不得假装保存成功或静默删除其他草稿腾空间。

## 7. 许可与交付限制

Agentation 当前许可证为 PolyForm Shield，包含竞争性产品限制；当前项目自身为 MIT，不能把第三方组件重新标为 MIT。

用户确认技术路线不等于作者许可，内部集成也不自动豁免。依赖纳入前需记录精确版本及许可，并确认目标使用方式可接受；若无法确认，停止依赖集成并请求授权方向。不得删除或隐藏许可声明。

本设计不授权联系作者、推送 GitHub、合并 PR、发布 npm/ZIP 或安装到用户常用 Chrome。公开分发必须另行解决许可并得到发布确认。v0.0.7 仍保持暂停。

## 8. 验收

| 场景 | 通过条件 |
|---|---|
| 普通网页文字与元素批注 | 能各自新增、编辑、删除；编号/计数/预览一致 |
| 会话型长页面 | 多条问题保留各自引用；列表重渲染后不错误高亮 |
| 刷新、多标签页和 SPA 导航 | 刷新恢复当前草稿；标签页和页面之间不串内容、不覆盖 |
| 模式与布局 | 非批注模式不阻断页面；设置可操作；明暗主题与现有 390px 面板可用 |
| 隐私与消息边界 | 没有宿主存储写入和未确认网络发送；伪造页面消息不能发送/读凭据 |
| 超限和存储失败 | 明确提示截断/超限/未保存，无静默丢失 |
| 批量提交 | 一次确认产生一批请求，编号/引用/目标与预览一致 |
| 失败、超时、重复点击 | 草稿保留；不自动重发未知结果；正常双击不重复发送 |
| 异步状态变化 | 新会话/设备/目录切换后旧结果不污染新状态；新草稿不被旧批次清空 |
| 既有功能回归 | 登录、连接恢复、目录审批、普通提问、会话跳转继续可用 |

纯逻辑和组件使用现有单元测试框架，执行 typecheck、test、build。所有真实浏览器操作仅使用 Ego，按用户规则逐轮截图报告；不运行包含 Playwright 的 verify/smoke/e2e 脚本。夹具验证与实际安装的 MV3 验证必须分别记录，前者不能冒充后者。真实 SDK/服务端集成只在已授权的测试环境进行，未覆盖之处如实列出。
